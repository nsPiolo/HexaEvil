# UnityProject/

Emplacement prévu pour le projet Unity 6 (à créer depuis Unity Hub, en
choisissant ce dossier comme racine du projet — ne pas laisser Unity créer
un sous-dossier supplémentaire).

Structure de scripts cible une fois le projet créé, voir
`docs/ARCHITECTURE.md` §1 :

```
UnityProject/Assets/_Project/Scripts/Core/...
UnityProject/Assets/_Project/Scripts/Presentation/...
UnityProject/Assets/_Project/Scripts/Data/...
UnityProject/Assets/_Project/Scripts/Bootstrap/...
UnityProject/Assets/_Project/Scenes/...
UnityProject/Assets/_Project/Prefabs/...
UnityProject/Assets/_Project/Art/...
UnityProject/Assets/_Project/Audio/...
UnityProject/Assets/Tests/EditMode/...
UnityProject/Assets/Tests/PlayMode/...
```

Réglages obligatoires après création (voir `CONTRIBUTING.md` §6) :
- `Edit > Project Settings > Editor > Asset Serialization Mode` = `Force Text`
- `Edit > Project Settings > Editor > Version Control Mode` = `Visible Meta Files`

`Library/`, `Temp/`, `Obj/`, `Build*/`, `Logs/`, `UserSettings/` sont ignorés
par `.gitignore` — ne jamais forcer leur ajout.
